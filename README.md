# ม็อกอัพระบบรับสมัครนักศึกษา

คณะเทคโนโลยีและการจัดการอุตสาหกรรม มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ วิทยาเขตปราจีนบุรี

เว็บม็อกอัพ (HTML/CSS/JS ล้วน) สำหรับจำลองการใช้งานจริงของผู้สมัคร หน้าตาและลำดับหน้าตรงกับไฟล์ Figma "mockup"
ทุกหน้ามีข้อมูลตัวอย่างใส่ไว้แล้ว กดปุ่มเพื่อไปหน้าถัดไปได้ ไม่มีระบบหลังบ้าน ไม่มีการบันทึกข้อมูลจริง

## วิธีเปิด

- ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย
- หรือเปิดผ่านเซิร์ฟเวอร์ในเครื่อง: `python -m http.server` แล้วเข้า http://localhost:8000

ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Noto Sans Thai และแผนที่ในหน้าติดต่อ

## Flow การใช้งาน

```
หน้าแรก → หลักสูตร → รายละเอียดหลักสูตร      (ดูได้โดยไม่ต้องเข้าสู่ระบบ)
                         ↓ สมัครหลักสูตรนี้
                     เข้าสู่ระบบ
                         ↓
 ① ข้อมูลส่วนตัว → ② ช่องทางติดต่อ → ③ การศึกษา   (กรอกเฉพาะครั้งแรก)
                         ↓
 ④ รอบและเอกสาร → ⑤ ตรวจสอบ → ⑥ ชำระค่าสมัคร → สมัครเรียบร้อย
                         ↓
 ใบสมัครของฉัน: ตรวจสอบคุณสมบัติ → สัมภาษณ์ → ประกาศผล → ยืนยันสิทธิ์ที่ mytcas → รายงานตัว
```

## โครงสร้างไฟล์

```
css/app.css   สี ฟอนต์ และชิ้นส่วน UI (ค่าสีตรงกับตัวแปร Theme ใน Figma)
js/data.js    ข้อมูล 12 หลักสูตร รอบรับสมัคร และวุฒิการศึกษา
js/mock.js    แถบหัว ท้ายเว็บ การ์ดหลักสูตร แถบขั้นตอน (ใช้ร่วมทุกหน้า)
assets/       รูปอาคารและไอคอน
```

## หมายเหตุ

- วันที่รับสมัคร ค่าสมัคร 400 บาท เลขใบสมัคร และข้อมูลผู้สมัคร เป็นข้อมูลตัวอย่าง
- ข้อมูลติดต่อและพิกัดแผนที่ (14.160517, 101.349076) มาจากเว็บไซต์มหาวิทยาลัย kmutnb.ac.th
- รองรับทั้งจอคอมและมือถือ
